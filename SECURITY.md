# Política de segurança

Não abra uma issue pública com dados financeiros, tokens, credenciais ou detalhes exploráveis. Use **Report a vulnerability** na aba Security. Se indisponível, contate o proprietário por um canal privado já conhecido.

Inclua versão afetada, impacto e passos sem dados reais. Não teste contas de terceiros. Segredos expostos devem ser revogados imediatamente; apagar o commit não torna o segredo seguro novamente.
